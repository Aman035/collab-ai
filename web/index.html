§ 01 — The problem

AI coding agents are
single-player.

Real engineering — debugging, reviews, mentorship — is rarely solo work. Today's options for pairing all break in some important way.

  1. 01

    Screen-share is passive.

    One person drives, the other watches. The observer can't ask their own question without interrupting the driver's flow.

  2. 02

    Shared accounts break the rules.

    Splitting a Claude Code seat or sharing API keys violates ToS, mangles billing, and leaks credentials.

  3. 03

    Async git loses the live reasoning.

    By the time the diff lands, the chain of thought that produced it is already gone.

§ 02 — How it works

Two binaries. One conversation.

Each participant runs collab-ai locally. The binary speaks MCP to the agent and connects peer-to-peer to other participants over Gensyn Axl.

§ 03 — What you get

Built for developers,
not platforms.

Bring your own agent

Works with any MCP-capable agent — Claude Code today; Codex and Cursor next. The protocol is agent-agnostic by design.

Bring your own keys

Each peer talks to its own model with its own API key. Quota, billing, and credentials never leave your machine.

Peer-to-peer

No central server, no hosted state. Connections route through the encrypted Yggdrasil mesh that Gensyn Axl rides on.

Opt-in sharing

Only ./shared/ and the conversation log cross the network. Files outside the dir, your env, and tool-call results stay local.

§ 04 — Quick start

Two terminals. One invite.

One command per side. Share the invite code out-of-band — Slack, SMS, carrier pigeon — and you're paired.

terminal A — host 
$ collab-ai host --dir ./shared

  Invite code:
  COLLAB-...c0c2-7eb45cac54

  ▸ Waiting for peers...
terminal B — joiner 
$ collab-ai join COLLAB-...c0c2-7eb45cac54 \
    --dir ./shared

  ✓ Connected to host.
  ▸ Ready.

Then point your AI agent at the local collab-ai binary as an MCP server. Your prompts and the agent's answers flow into a shared log; edits in ./shared/ propagate to everyone.

§ 05 — Install

One go install away.

  1. 01

    Install collab-ai

    $ go install github.com/Aman035/collab-ai/cmd/collab-ai@latest

    Requires Go 1.22 or newer.

  2. 02

    Install the Axl daemon

    collab-ai spawns Gensyn Axl's node binary as a child process to handle peer routing. Build it once and put it on your PATH: 

    $ git clone https://github.com/gensyn-ai/axl.git
$ cd axl && go build -o node ./cmd/node/

    Homebrew & install.sh
